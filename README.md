# Heart Rate Monitor Progressive Web App

This is a simple PWA app that connects to a Bluetooth enabled heart rate monitor.

## Features

- Connect to heart rate monitor without downloading any apps
- Record workouts
- Measure workout stats to get a report
  - exercise time
  - avg heart rate
  - max heart rate
  - calories burned
- Map heart rate zone over time
- Track of how much time was spent in each zone (1-5)
- Measure heart rate variability
- Export workout report as JSON
- Save workout reports on device
